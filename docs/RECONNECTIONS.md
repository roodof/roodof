# Explicit session annotation transfer

0.9.12 local candidate. B01b moves saved annotations from a missing/archived row to a currently loaded live row. It does not prove a file move, change session codes, reconcile usage or search another folder. Add the new source and scan first. A known archived source and target must use the same agent; a source still live is refused. Legacy references without source metadata need the user's explicit choice.

The authenticated settings API searches in pages of 20, independently of report filters and the frozen 400-session work picker. Preview is read-only. Confirmation requires its content revision and an explicit boolean; a changed scan or metadata invalidates it. Work memberships replace the old code with the target once per work, preserving other memberships, notes and frozen follow-ups. Conflicting reviews and budgets require source/target choices. Chosen notification history is retained with a fresh budget revision; existing coverage and monitoring rules still apply.

The existing three annotation formats remain unchanged. `session-reconnection.json` is a bounded 16 MiB private write-ahead/last-undo record containing validated before/after annotation snapshots. Only the three fixed annotation filenames are allowed. Duplicate keys, invalid base64 and unsupported formats are rejected. The shared cache lock is reentrant for the same thread/folder; its recovery hook completes pending commits before metadata is exposed. Annotation readers also take that lock. Unexpected external edits or corruption preserve the record and block changes. Close older PLER versions first: they do not understand this recovery protocol.

Conditional inverse patches preserve unrelated later entries and work notes. Edited affected memberships/reviews/budget configurations block undo. Monotonic automatic notification acknowledgements are allowed. Undo is journaled too. Only the last transfer is kept; clearing its copy leaves annotations unchanged. Private backups finish pending writes first and include resulting annotations, not the recovery copy. Normal exports omit it. Deleted work notes may remain in this private copy until it is cleared or replaced.

Real cross-disk/WSL, clean-Windows and real-user acceptance remain Q01/SON. Invented developer checks do not close it. Public Site/feed/downloads remain 0.9.11 until a separate release action.
