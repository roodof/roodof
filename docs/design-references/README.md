# Design references

READMEs, rule files and selected component sources used for DESIGN.md. `sources.json` records each URL and SHA256.
The raw GitHub tree listings (`*-tree.json`, about 12 MB) are kept outside this repository, next to the design-foundation report; their URLs and hashes in `sources.json` identify them.
