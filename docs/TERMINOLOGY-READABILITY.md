# Kavramlar ve okunabilirlik — UX5/6

| Türkçe | English | Anlam |
| --- | --- | --- |
| Hesap kotaları | Account limits | Sağlayıcının hesap sınırları; kayıtlardaki son ölçümler. |
| Kullanım uyarısı | Usage alert | Kullanıcının bir oturum için seçtiği token/USD eşiği. |
| API fiyat karşılığı | API price equivalent | Kaydedilmiş kullanımın standart API fiyatlarıyla karşılığı. |

API fiyat karşılığı fatura/abonelik harcaması değildir; kısmi veya fiyatlanamayan kayıt nitelemeleri korunur. Kullanım uyarısı mevcut %80/%100 ve uygulama açıkken izleme kurallarını kullanır; hesap kotasını değiştirmez, ajanı durdurmaz. Hesap kotası canlı sağlayıcı sorgusu değildir.

Ortak yardımcı ölçüler: etiket/açıklama en az12px; gövde13px; bölüm başlığı15px; açıklama satır aralığı1.6; bölüm boşluğu16px; kontrol aralığı8px. Renkler ve font aileleri aynı. Kurtarma yolları ve uzun kota durumları sarılır. Güncelleme penceresi kompakt16px; çevrimdışı yardım aynı koyu tasarımdadır ve kısa kavram sözlüğü içerir.

Menü ve komut arama ortak ekran adını kullanır. Uyarı başlığı, erişilebilir adı ve masaüstü bildirimi tutarlıdır. İç API alanları, veri şeması ve hesaplama değişmez.400 seçici dosyası dondurulmuş kalır. Gerçek kullanıcı/WSL/temiz Windows kabulü son görevdir; buradaki kontroller geliştirici doğrulamasıdır. Yayın izni verilmedi; public0.9.11 aynı.
