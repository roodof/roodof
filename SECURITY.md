# Security policy

Roodof reads Claude Code and Codex logs on your own computer, so security reports matter to us.

## Reporting a vulnerability

Please report privately through GitHub: **Security → Report a vulnerability** on this repository. Do not open a public issue for a security problem.

Include the Roodof version, your operating system and the steps that show the problem. Do not send real prompts, replies, commands, tool output, access tokens or startup addresses containing `#access=`; invented sample data is enough.

## Supported versions

Only the latest released beta receives fixes.
